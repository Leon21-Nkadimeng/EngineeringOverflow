###  Functional Requirements

#### Authentication Requirements

- users must be able to register an account.
- users must be able to login (using email and password) and logout.
- users must be able to reset their password if they forget it
- users must be able to reset their password while logged in.
- users must be able to update their email.
- users must be able to deactivate their account while logged in.
- The system must securely hash user passwords before storing them in the database.
- The system must verify email addresses when they're changed.
- The system must verify phone numbers when they are changed.

### 

### Profile Management Requirements
- The system must ensure that each public username is unique.
- Users must be able to set and change their profile image.
- Users must be able to provide and update their bio.
- Users must be able to provide and update their public username.
- Users must be able to provide and update their date of birth.
- Users must be able to provide and update their location.
- Users must be able to provide and update links to their social profiles.
- Users must be able to provide and update their educational experience.
- Users must be able to provide and update their employment information.
- Users must be able to provide one or more engineering disciplines.
- Users must be able to view other users' public profile information.
- The system must allow users to control which profile information is publicly visible.
- The system must not expose a user's date of birth; the date of birth must be private by default.

###

### Posts Requirements
- Users must be able to ask questions.
- Users must be able to answer questions.
- Users must be able to edit their questions within an acceptable amount of time.
- Users must be able to edit their answers within an acceptable amount of time.
- Users must be able to save questions and answers.
- A user must be able to recieve a notification when another user answers their question.
